## 2. Входные данные и адресация

| Параметр | Значение |
|---|---|
| Архив | `cs2_212C3300000.rar`, 42 578 727 bytes |
| Raw image | `cs2_212C3300000.bin`, 83 890 176 bytes = `0x5001000` |
| Base | `0x212C3300000` |
| Конец образа, exclusive | `0x212C8301000` |
| Правило | `VA = base + RVA`, `RVA = file offset` |
| Заявленный entry | VA `0x212C82F1690`, RVA `0x4FF1690` |
| BIN SHA-256 | `3224604483481c57a18ccfb20448a5e634a9583421abfac3a2712bba5cc77f27` |
| RAR SHA-256 | `763e580f9827c46c23eb5e5b9e33ec643d7ee9221d2b91083ef1f623989cfd87` |

PE header не распознан, `MZ` в начале отсутствует, первые `0xA00` bytes нулевые. База взята из предоставленной информации и согласуется с адресными свидетельствами, не прочитана из PE. Строки `neverlose_cs2.dll`, dependency paths и particle assets согласуются с происхождением, но не дают независимой аутентификации сборки. Версия продукта не установлена.

Характеристика pre-entry предоставлена с файлом и согласуется с нулевыми sampling tables и offsets-заглушками. Это не независимо измеренный момент остановки процесса. В исходном образе несколько schema offsets содержат `0x13371337`; runtime-структуры нельзя читать по этому значению как по настоящему смещению.
