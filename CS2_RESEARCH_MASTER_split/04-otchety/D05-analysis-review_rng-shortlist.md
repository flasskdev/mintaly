# Приложение D05. `analysis/review_rng/shortlist.md`

**Дословный исходный отчёт.** Даты/статусы/неизвестные роли внутри относятся к своему этапу. При расхождении использовать актуальный свод и поздние доказательства. Пути внутри текста — исторические: соответствующие материалы встроены в MD/CPP и находятся через поиск исходного пути.

# Актуальные точки продолжения

Уже получены C-псевдокод `0x505f50`, `0x511d50`, `0x3375a0`, `0x50dd90`, `0x528b90`, `0x52b250`, `0x309500`. Повторный запуск Ghidra для получения тех же файлов не нужен. Разбор aim/fire — `summary.md`; угловой прогноз — `addendum_vector_sampling.md`; candidate/history фильтрация — `../CORE_ADDENDUM_RU.md`.

Дальнейшие задачи:

1. Исправить/уточнить CFG и типы `0x528b90`: успешное создание C сопровождалось bad-instruction и non-existing-memory предупреждениями. До этого нельзя объявлять её полностью восстановленным hit test.
2. Проследить запись score/flags кандидатной структуры `0x30` и происхождение данных `0x50dd90`; это нужно для реального значения ranking и всех ветвей выбора цели.
3. Найти producers кольца из 16 пространственно-временных записей по `0x500`, их aging/validation и apply/restore сущности. Сам отбор до двух записей уже выделен.
4. Установить producers двух угловых состояний `0x3375a0`, прежде чем назвать их recoil/punch.
5. Отдельно выделить настоящий weapon spread/hitchance и damage/penetration, не пользуясь совпадениями UI RNG, шрифтового spread или protobuf-полей как доказательством.
6. Для необязательного уточнения визуального эффекта: RVA `0x63a320` (создание/lookup handle), `0x636050` (setter control points), `0x2eab50` (источник yaw), `0x645b20` (secondary resource queue).
7. Псевдокод `0x4fd710` требует корректных prototype/control-flow для `0xdc5d20`; ASM показывает строковый selector, который автоматический C искажает.

Все короткие адреса — RVA, base `0x212c3300000`. `callee_addresses.txt` сохранён как исторический список первого review: первые четыре адреса из него уже декомпилированы в `decompiled_core/`. Отсутствие ребра в SQLite не доказательство отсутствия вызова.
