# Приложение D03. `analysis/review_rng/addendum_vector_sampling.md`

**Дословный исходный отчёт.** Даты/статусы/неизвестные роли внутри относятся к своему этапу. При расхождении использовать актуальный свод и поздние доказательства. Пути внутри текста — исторические: соответствующие материалы встроены в MD/CPP и находятся через поиск исходного пути.

# `3375a0`: временной прогноз угловых поправок

**Высокая уверенность:** это не простой vector sampling/lerp, а **кэшируемое затухание углового состояния с интегрированием скоростного входа и кватернионной интерполяцией по времени**. Так уточняется роль двух вызовов из `50fb10`: они вычисляют две временно согласованные угловые поправки, чьи компоненты затем используются для коррекции aim. **Recoil/aim-punch — обоснованное предположение; имена producers и назначение каждой из двух поправок неизвестны.**

Источник — только `decompiled_features/212c36375a0.c` и константы dump. Новые callees/файлы не исследовались; `511d50` не перечитывался. Адрес функции: VA `0x212c36375a0`, RVA `0x3375a0`. Ниже `L` — строки этого C; dump offset = VA − `0x212c3300000`.

## Операция

1. **Время, L96–142:** нормализует исходную пару tick/fraction (fraction фактически в XMM3; тип `param_4` восстановлен плохо). От целевой пары `param_7/param_8` вычитает исходную, с переносом/заёмом; `t=max(delta_ticks,0)/64`, `s=128*t`, `k=floor(s)`, `alpha=s−k` для обычных конечных входов.
2. **Кэш, L143–203:** ключ — нормализованное исходное время и два Vec3 (`param_5`, `param_6`). При изменении сбрасывает samples, seed=`param_5`. Хранит Vec3 по 12 bytes; достраивает до индекса `min(k+1,128)` — максимум **129 точек, включая нулевую**, то есть горизонт 1 секунды.
3. **Шаг прогноза, L208–409:** `h=1/128`, `x0=param_5`, `v0=param_6`. С учётом FP-округлений:

```text
y = a*x[i],  a=0.939413070679 ≈ exp(-8*h)
D(x[i]) = |y|>18*h ? y*(1−18*h/|y|) : 0
v[i] = F(-4.5*i*h)*v0;  при |v[i]|²<1/1024 → 0
x[i+1] = D(x[i]) + (h/2)*(v[i]+v[i+1])
```

Это мультипликативное и линейное затухание состояния плюс **трапецеидальное интегрирование** скоростного вклада. `F=func_0x0212c4093800` предположительно `expf`; без чтения callee это не установленный символ. После лимита кэша недостающий sample=`last*G(a,index−last_index)`, где `G=4098310` предположительно `powf` (L417–479): не продолжение полного интегратора.

4. **Между samples, L440–657:** обе соседние тройки ограничиваются покомпонентно `[-89,+89]`, переводятся из Euler degrees в quaternions через sin/cos-подобный слот и half-angle. Вес интерполяции полиномиально корректируется по `alpha` и `abs(dot(q0,q1))`; выбирается согласованный знак quaternion, смесь нормализуется, нулевая норма заменяется identity `(0,0,0,1)`. Это **скорректированный nlerp / fast-slerp-like**, не обычный Vec3 lerp и не доказанный точный SLERP. Далее quaternion → rotation matrix → Euler degrees; при сингулярности отдельная ветвь с roll=0.
5. **Выход, L658–681:** при квадрате длины углов `<1/1024` возвращает ноль; `param_9!=0` удваивает все три компоненты. RNG в показанном теле отсутствует.
